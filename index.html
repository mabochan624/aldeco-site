MISSION

約束を守るために、
職人を最高にする。

きつい仕事を、
割に合う最高の仕事に変える。

私たちの仕事は、作って終わりじゃない。何十年も、そこで暮らす人の土台になる。
だから、手抜きの仕事は一つも出せない。
でも、最高の仕事は、最高の職人からしか生まれない。
きつくて、危険で、体を酷使するこの仕事。人より休みが多くて、給料が高くて、
誇れる仕事じゃなければ、最高の職人は育たない。
だから私たちは、技術の力できつい仕事を「割に合う仕事」に作り変える。
まず自分たちの会社で証明し、その先で業界全体を変えていきます。

WHY US

この仕事を変えることに、
一番価値がある。

なくならない仕事なのに、人が減っている

需要は社会インフラそのもの。「やらない」という選択肢が世の中に存在しない仕事です。

だからこそ「割に合う仕事」に変える価値がある

需要が減らず供給が減る場所では、働く人の価値が上がり続けます。ここを変えた者が、業界の未来を作ります。

それができるのは、現場を知る自分たちだ

現場の腕と、道具やアプリを生み出す発明力。両方を持つ会社はほとんどありません。

VALUES

技術とは、腕だけのことじゃない。

段取りも、道具も、アプリも、人の育て方も、全部が技術。ALDECOの「技術を極める」は、この4本柱でできています。

VALUE 01

腕を磨く

現場の技術で誰にも負けない。品質と速さで信頼をつくる。

VALUE 02

やり方を発明する

合言葉は「脳動(ノウドウ)」。脳を動かして、道具もアプリも段取りも「もっと楽にできないか」を問い続ける。

VALUE 03

誰でもできる形にする

自分にしかできない仕事を残さない。頭を使う仕事を、仕組みと育成で身につく形に落とす。

VALUE 04

安全と確実さを譲らない

危険な仕事だからこそ、早さより先に安全。品質は削らない。

PROVE IT

COMMITMENT

言うだけじゃない。数字で証明する。

「割に合う仕事に変える」を、まず自分たちの会社の数字で証明します。

年間休日
110日 → 120日へ

全産業平均(116.6日)を超え、週休2日相当の120日を目指します。

給与
3年で+2割

目指すのは「業界平均+2割」。効率化で生んだ利益は働く人に返します。

育成
3年で一人前

手順・道具・段取りを標準化し、未経験から3年で一人前になれる仕組みを作ります。
